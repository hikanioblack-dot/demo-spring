# Автосервис — Задание 3

## 📌 Тема
Сервис для управления автосервисом: приём заказов на ремонт, назначение механиков, отслеживание статусов выполнения работ.

## 🧩 Основные сущности
1. **Клиент (Client)**
    - Имя, телефон (уникальный), email (уникальный)
2. **Автомобиль (Car)**
    - Марка, модель, год выпуска, гос. номер (уникальный), привязан к клиенту
3. **Механик (Mechanic)**
    - Имя, специализация, телефон (уникальный)
4. **Заказ (Order)**
    - Описание, статус (`принято`, `в работе`, `готово`, `выдано`), дата создания, привязан к автомобилю и клиенту
5. **Назначение (Assignment)**
    - Связь заказа с механиком, статус выполнения

## ⚙️ Операции

### 🔁 CRUD (Create, Read, Update, Delete)
Для всех 5 сущностей реализован полный набор:
- Создание (`POST`)
- Получение списка и по ID (`GET`)
- Обновление (`PUT`)
- Удаление (`DELETE`)

### 🚀 Бизнес-операции (5 шт.)
1. **Зарегистрировать нового клиента вместе с его автомобилем.**
2. **Оформить ремонт: создать заказ и сразу назначить механика.**
3. **Выдать заказ клиенту**
4. **Удалить клиента вместе со всеми его автомобилями и заказами.**
5. **Получить отчёт: все активные заказы с клиентом, автомобилем и назначенным механиком.**  
   
## 🗃 База данных
- Используется **PostgreSQL**
- Все таблицы связаны внешними ключами (`FOREIGN KEY`)
- Добавлены ограничения:
    - `UNIQUE` на телефон, email, гос. номер
    - `CHECK` на год выпуска и статус заказа
- Тестовые данные загружаются автоматически при старте
