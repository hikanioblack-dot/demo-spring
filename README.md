# Автосервис — Задание 4: Базовая безопасность API

## 🛠 Реализованные требования
1. **Spring Security**: Подключен и настроен модуль безопасности.
2. **Аутентификация**: Реализована через **Basic Auth**.
3. **Ролевая модель (RBAC)**:
    - `ROLE_ADMIN`: Полный доступ ко всем CRUD-операциям и созданию персонала.
    - `ROLE_MECHANIC`: Просмотр данных и управление бизнес-логикой ремонта.
    - `ROLE_CLIENT`: Доступ только к "Личному кабинету" (свои авто и заказы).
4. **Регистрация**:
    - Публичный эндпоинт `/auth/register`.
    - Сбор контактов (Email, Phone).
    - Автоматическое создание профиля клиента.
    - Возврат Client ID пользователю.
5. **Безопасность данных**:
    - Пароли хэшируются с помощью **BCrypt**.
    - Валидация пароля: проверка длины, регистра, цифр и спецсимволов.
    - **Data Ownership**: Клиент не может получить доступ к чужому автомобилю по прямому ID (возвращается 403 Forbidden).
