# Автосервис — Задание 5: JWT и управление сессиями

## 🛠 Что реализовано
1. **JWT (JSON Web Token)**:
    - Полный переход с Basic Auth на Stateless аутентификацию.
    - Использование **Access Token** (15 мин) для доступа к API.
    - Использование **Refresh Token** (7 дней) для получения новой пары токенов.
2. **Session Management**:
    - Новая сущность `UserSession` для хранения активных Refresh-токенов в БД.
    - Статусы сессий: `ACTIVE`, `USED`, `REVOKED`.
3. **Безопасность (Reuse Detection)**:
    - Реализован механизм обнаружения повторного использования Refresh-токена.
    - Если токен со статусом `USED` предъявляется повторно, сессия помечается как `REVOKED`, и доступ блокируется.
4. **Lombok**: Проект переведен на использование Lombok для чистоты кода.
